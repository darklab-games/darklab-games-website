Both are the current LinkedIn profile pictures, at the 200×200 that LinkedIn
serves publicly. If you want them sharper on high-DPI screens, save the
originals from LinkedIn at 400×400 or larger and overwrite these files —
nothing else needs changing.

The studio page falls back to an initials mark if a file is missing.
Filenames are configured in `src/lib/site.ts`.
